# Roadmap

## v0.1 — local evidence receipts (complete locally)

- strict contracts, deterministic creation, local verification, comparison;
- Solana identifiers, generated schemas, CLI, tests, demo, CI, governance;
- no publication without separate approval and review.

## Candidate v0.2

- optional detached signatures with explicit key identities;
- pluggable, offline snapshot acquisition manifests (still never executed from receipts);
- richer Solana commitment/finality metadata without claiming independent chain verification;
- migration tooling with byte-for-byte fixtures.

## Explicitly deferred

On-chain anchoring, wallet operations, network fetchers, hosted services, model scoring, and performance benchmarks require separate threat models and milestone approval.
